# 나는 AI가 아니야! ☕

**작은 모닥불 마을에서 5~7명의 DeepSeek가 서로를 의심하는 모습을 구경하는 로컬 관전 게임.**

실제로는 모두 AI 배우지만, 게임 속에서는 **인간 팀 vs 잠입 AI 팀**입니다. 모카, 두부, 루나, 감자, 보리, 후추, 나비가 저마다의 말투로 “나는 AI가 아니야!”를 외칩니다. 플레이어는 참여하지 않고 불멍하듯 구경해도 됩니다.

## 바로 실행하기 · Fedora / Linux

**Python 3.11+만 필요합니다. pip, npm, Docker, CUDA, 모델 다운로드는 필요 없습니다.**

```bash
# PR 브랜치를 바로 체험할 때
git clone --branch feat/cozy-ai-mafia https://github.com/yabsed/mafia-game.git
cd mafia-game
python3 run.py
```

브라우저에서 **http://127.0.0.1:8765**를 엽니다. `모닥불 켜기 → 무료 데모 → 마을 열고 관전하기`를 누르면 됩니다. 저장된 게임은 서버를 다시 켜면 **일시정지 상태**로 복구됩니다. 포트 변경은 `python3 run.py --port 8766`입니다.

Python이 없다면 Fedora에서 `sudo dnf install python3 git`로 설치합니다. Python 3.11~3.14를 대상으로 합니다. AI 추론은 DeepSeek 서버에서 이루어지므로, 16GB RAM / RTX 3050 노트북에서도 로컬 대형 모델을 올릴 필요가 없습니다. 실제 Fedora 44 장비에서의 검증은 아직 하지 않았습니다.

## DeepSeek 라이브 켜기

```bash
cp .env.example .env
chmod 600 .env
# 텍스트 편집기로 .env를 열고 DEEPSEEK_API_KEY= 뒤에 본인의 키를 입력합니다.
python3 run.py
```

`.env` 예시:

```dotenv
DEEPSEEK_API_KEY=your-key-here
TOTAL_BUDGET_USD=8.00
```

키를 바꿨다면 서버를 재시작하고 브라우저도 새로고침합니다. `새 마을 → DeepSeek 라이브`를 선택하고 실제 과금 동의에 체크하세요. **키를 채팅에 붙여 넣거나 Git에 커밋하지 마세요.** 키 입력 UI는 의도적으로 없습니다. 키는 서버 프로세스에만 있고, 브라우저·JSON 기록·SQLite에는 저장하지 않습니다. 셸 환경변수가 `.env`보다 우선합니다.

기본 모델은 `deepseek-flash`, 선택 모델은 `deepseek-v4-pro`입니다. 기본 thinking 모드는 명시적으로 **disabled**로 바꿉니다. 출력은 차례당 최대 512토큰, 캐릭터별 독립 요청이며 한 번에 하나만 호출합니다. 키가 없어도 데모는 됩니다. **라이브를 몰래 데모로 바꾸지는 않습니다.**

## 관전하는 방법

| 기능 | 동작 |
| --- | --- |
| 자동 관전 / 일시정지 | 다음 주민의 행동을 차례로 진행합니다. 스페이스로도 전환합니다. |
| 한 차례 | 일시정지 중 주민 한 명의 발언·투표·밤 행동만 진행합니다. |
| 재생 속도 | 응답이 끝난 뒤 다음 행동까지 4 / 2.4 / 1.2 / 0.3초 기다립니다. API 자체 응답 속도는 바꾸지 않습니다. |
| 주민 클릭 | 최근 발언 확인, 나만의 의심 표시. 실제 게임에는 영향을 주지 않습니다. |
| 감독 모드 | 숨은 정체와 비공개 투표·밤 행동·캐릭터의 일기를 봅니다. |
| 공개 대화 / 비밀 일기 | 공개 토론과 비공개 정보를 분리해서 봅니다. 일기는 짧은 연출용 메모이지 모델의 내부 추론이 아닙니다. |
| 대화 되감기 | 기록 패널만 과거로 돌립니다. 마을 상태나 게임 진행을 되돌리지는 않습니다. `지금`으로 복귀합니다. |
| 기록 서랍 | 최근 30개 게임을 불러와 이어보거나 완결된 기록을 읽습니다. 오래된 기록도 DB에는 남습니다. |
| ↓ 저장 | 현재 보기의 JSON 기록을 다운로드합니다. 감독 모드 또는 게임 종료 후에는 비밀 정보도 포함됩니다. |
| 소리 켜기 | 선택형 낮은 합성 배경음. 외부 음원 요청이나 자동 재생은 없습니다. |

진행 중인 유료 API 요청은 일시정지로 과금 취소할 수 없습니다. **현재 요청 한 개를 마저 처리한 뒤 추가 호출을 멈춥니다.** 새 마을/기록 불러오기는 그 요청이 끝난 뒤 가능합니다. 탭을 닫아도 서버가 켜져 있으면 현재 판의 자동 관전이 계속될 수 있으므로, 먼저 일시정지하거나 터미널에서 `Ctrl+C`로 종료하세요. 다음 판을 자동 구매/시작하지 않습니다.

## 게임 규칙

5·6명은 잠입 AI 1명, 7명은 2명입니다. 인간 팀에는 항상 **분석가 1명, 수리공 1명**, 나머지는 일반 인간이 있습니다.

- **낮:** 생존자가 1~2바퀴 토론한 뒤 비밀 투표. 전원 선택 후 동시에 공개합니다. 자기 투표 불가, 기권 가능. 최다 득표자가 퇴장하고 인간/AI 소속만 공개됩니다. 동률은 동률 후보에 한해 1회 결선, 다시 동률이거나 전원 기권이면 추방하지 않습니다.
- **밤:** AI가 인간 한 명을 지목, 분석가는 생존자 한 명의 소속 조사, 수리공은 한 명 보호. 수리공의 연속 자기 보호는 허용합니다. AI 지목 동률은 시드 기반으로 결정합니다. 모든 밤 행동은 동시에 처리되며, 그날 지목당한 분석가도 조사 결과를 얻습니다. 결과를 공개하거나 거짓말하는 것은 다음 낮 캐릭터의 선택입니다.
- **종료:** 모든 AI가 퇴장하면 인간 승리. 생존 AI 수가 인간 수 이상이면 AI 승리. 기본 8일(설정 3~12일)을 넘기면 무승부. 종료 시 관전자에게 모든 정체가 공개됩니다. 퇴장은 비폭력적으로 표현합니다.

실제 규칙의 권위는 Python 엔진입니다. 모델은 **발언과 선택만** 제안합니다. 잘못된 대상/자기 투표/탈락자 선택은 무효·기권 처리됩니다. 모델이 역할, 생존 여부, 승패 또는 예산을 변경할 수 없습니다.

## $8 예산 보호가 의미하는 것

`TOTAL_BUDGET_USD=8.00`은 **이 앱의 누적 추정 지출 제한**입니다. DeepSeek 계정의 실제 잔액을 조회한 수치가 아닙니다. 한 판 예산은 기본 `$0.15`이며 새 판을 만들 때 바꿀 수 있습니다. Pro는 더 비싸므로 기본 예산에서 더 일찍 멈출 수 있습니다.

가격 확인일: **2026-09-19**, 단위 USD / 100만 토큰. 더 비싼 **피크 단가를 항상 사용**합니다.

| 모델 | 입력 캐시 미스 | 입력 캐시 히트 | 출력 |
| --- | ---: | ---: | ---: |
| `deepseek-flash` | $0.30 | $0.006 | $1.20 |
| `deepseek-v4-pro` | $1.32 | $0.044 | $3.96 |

공식 자료: [가격표](https://api-docs.deepseek.com/quick_start/pricing/) · [thinking 설정](https://api-docs.deepseek.com/guides/thinking_mode/) · [JSON 출력](https://api-docs.deepseek.com/guides/json_mode/). 가격이나 모델 별칭이 바뀌면 `mafia/provider.py`의 `RATES`를 확인하고 갱신하세요. 단가를 알 수 없는 임의의 모델은 호출하지 않습니다.

요청 직전 UTF-8 프롬프트 바이트 수 + 여유분을 입력 토큰 수의 **보수적 근사**로 쓰고, 최대 출력 512토큰 비용까지 SQLite에 예약합니다. 그 예약을 한 판/누적 한도 안에 확보하지 못하면 **API를 호출하기 전에 멈춥니다.** 응답의 `usage`가 있으면 캐시 히트·미스와 출력 토큰을 반영해 추정을 정산합니다. 계산은 `Decimal`입니다.

예를 들어 Flash에서 요청마다 캐시 미스 입력 3,000 + 출력 160토큰을 쓰는 요청 50회는 피크 기준 `$0.0546`입니다. **예시 계산일 뿐 판당 견적이나 보장된 게임 수가 아닙니다.** 실제 문맥 길이, 게임 일수, 모델과 가격 변경에 따라 달라집니다. 공식 과금과 실제 계정 잔액은 DeepSeek 콘솔이 기준입니다. 앱 밖에서 같은 키를 사용한 비용은 이 장부에 잡히지 않으며, 로컬 추정 제한이 공급자 측의 절대적인 결제 상한을 보장하지는 않습니다.

### 실패·재시작·중복 과금

HTTP 인증/잔액/요청/호출 제한 오류는 자동 재시도하지 않고 일시정지합니다. 타임아웃·연결 단절·서버 오류는 이미 과금됐을 수 있으므로 예약 비용을 유지한 채 그 행동을 안전한 기본 행동으로 넘기고 관전을 일시정지합니다. 잘린 응답/잘못된 JSON도 유료 수정 요청을 추가하지 않습니다.

각 요청은 게임 ID + 차례 ID로 영수증을 저장합니다. 응답 직후 앱이 꺼져도 저장된 응답을 재사용하며, 송신 중 종료되어 결과가 없으면 같은 요청을 자동 재전송하지 않습니다. 미확정 예약 비용은 UI에 따로 표시됩니다. 사용자 확인 없이 자동으로 환급 처리하지 않습니다.

**`data/village.sqlite3`를 삭제하면 누적 예산 장부와 게임 기록이 사라집니다.** 예산을 초기화하려고 파일을 지우지 마세요. 백업은 서버를 종료한 다음 `data/` 전체를 복사하세요. 다른 `MAFIA_DATA_DIR`을 사용하면 별도의 장부가 됩니다. 같은 폴더에는 한 서버만 실행할 수 있습니다.

## 정보 분리와 로컬 보안

`engine.view_for()`만 모델 입력을 구성합니다. 자기 역할·자기 메모·공개 발언·확정 투표·공개 퇴장 정보만 포함되며, AI만 동료 AI의 ID를 추가로 압니다. 전체 게임 상태, 다른 주민의 메모, 감독 모드 정보, 현재 라운드의 다른 비밀 투표는 모델에 전달하지 않습니다. 모델이 다른 모델과 직접 통신하거나 도구·셸·파일을 사용할 수 없습니다.

서버는 **127.0.0.1**에만 바인딩합니다. Host/Origin 검증, 세션별 요청 토큰, JSON 크기 제한, 정적 파일 허용 목록, CSP를 적용했습니다. 모델 텍스트는 `textContent`로 렌더링하며 HTML로 실행하지 않습니다. 유일한 `innerHTML` 사용은 로컬 SVG 캐릭터 템플릿이고 팔레트도 검증합니다. API 요청은 고정 HTTPS DeepSeek 주소만 사용하며 리디렉션과 환경 프록시는 사용하지 않습니다.

이는 신뢰하는 개인 노트북에서 혼자 쓰는 앱이지 공개 서버용 서비스가 아닙니다. **포트 포워딩하거나 공유 호스트에 노출하지 마세요.** 같은 OS 계정의 다른 프로세스·브라우저 확장·로컬 악성코드로부터의 격리는 제공하지 않습니다. DeepSeek 모드에서는 생성된 캐릭터 설정과 게임 대화가 DeepSeek로 전송됩니다. 데모는 외부 API/폰트/음원/CDN 요청이 없습니다.

## 구조 및 테스트

```text
run.py                  실행 진입점
mafia/engine.py          직렬화 가능한 순수 규칙·정보 분리
mafia/provider.py        DeepSeek HTTP / 무료 데모 / 출력 검증
mafia/storage.py         SQLite 스냅샷·Decimal 예약 장부·응답 영수증
mafia/server.py          로컬 HTTP·단일 worker·일시정지·복구
web/                    빌드 없는 한국어 HTML/CSS/JavaScript·SVG 마을
tests/                 unittest: 규칙·정보 분리·예산·HTTP·복구
tools/browser_smoke.py  선택형 Playwright UI 검사
```

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall -q mafia run.py
# Node가 설치되어 있을 때만 실행 (앱 런타임에는 불필요)
node --check web/app.js
```

테스트는 유료 API를 사용하지 않습니다. 데모 300판(5/6/7명 × 100시드), 동률·결선·밤 동시 행동·최대 일수, 정보 누출 방지, 원자적 예산 예약, 타임아웃·응답 손상·재시작, HTTP 출처 보호, 진행 중 일시정지를 검증합니다. CI는 Python 3.11/3.13/3.14 매트릭스로 구성했습니다.

선택형 브라우저 검사(별도 개발 의존성):

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install playwright
python -m playwright install chromium
python tools/browser_smoke.py
```

실제 API 키 없이 제작했으므로 **실제 DeepSeek 호출 품질·지연·청구는 검증하지 않았습니다.** 처음에는 기본 Flash와 작은 예산으로 한 판부터 확인하세요. 자세한 검증 범위는 [docs/verification.md](docs/verification.md)에 있습니다.
